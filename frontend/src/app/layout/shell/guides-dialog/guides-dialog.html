How to create collision for Gaussian Splat

Gaussian splats are visual data, not solid geometry. SplatIt loads collision from a separate .collision.glb file; create it offline with PlayCanvas SplatTransform.

  1. Prepare the source file. Work from a copy of your scene in a writable folder. SplatTransform accepts formats including .ply and .sog. Install the CLI with npm install -g @playcanvas/splat-transform, then verify it with splat-transform --version.
  2. Choose a seed point. Find a clear, walkable floor location inside the room and note its world-space X,Y,Z coordinates in the scene's own units (typically meters). The example below uses 0,1,0 only as a placeholder; replace it with a point that is actually on the floor area in your scene. The default walk capsule is about 1.6 units tall and 0.2 units in radius, so leave enough room around the point.
  3. Generate the collision mesh. For an enclosed indoor scan, run: 
    splat-transform ".\scene.sog" --filter-cluster --seed-pos "0,0,0" ".\scene.voxel.json" --voxel-external-fill --voxel-carve --collision-mesh smooth
    This PowerShell example uses scene.sog; replace "0,0,0" with your seed coordinates. Keep the input and output basenames the same so the generated mesh is named scene.collision.glb. For outdoor terrain, use --voxel-floor-fill instead of --voxel-external-fill and omit --voxel-carve.
  4. Install the sidecar. Copy scene.collision.glb beside the original splat in the scene library. The basename must match exactly, including capitalization; for example, Building.sog pairs with Building.collision.glb. SplatIt only needs the GLB sidecar; keep the voxel files if you want them for other tools.
  5. Verify it in SplatIt. Refresh the scene list, open the scene, and try Walk mode. If carving produces no mesh or walking is blocked, move the seed to open floor space and check that the room walls are closed enough for external fill.

Voxel generation can require substantial GPU memory for large splats. If it runs out of memory, use a GPU-capable workstation or try a larger --voxel-size for a coarser, lower-detail collision mesh.

Read the PlayCanvas collision-generation guide for voxel-size, fill, and troubleshooting options.

Install SplatTransform and PlayCanvas tools

SplatTransform is the local command-line tool used to create collision sidecars. It runs on Windows, macOS, and Linux with Node.js and npm.

  1. Install Node.js and npm. Download the current Node.js LTS installer or binary from nodejs.org and follow the instructions for your operating system:
    • Windows: choose the Windows Installer (.msi), run it, and leave the option to add Node.js to PATH enabled. Open a new PowerShell or Command Prompt window when installation finishes.
    • macOS: choose the macOS Installer (.pkg) for your processor, run it, and then open a new Terminal window.
    • Linux: choose the Linux binary for your processor or follow the Node.js instructions for your distribution. Add the Node.js binaries to PATH if your installer does not do that automatically, then open a new terminal.
    Important for Windows PowerShell: If PowerShell says scripts are disabled when you run npm, run this command under your own Windows account: 
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
    Confirm the prompt, then close and reopen PowerShell. This changes the policy for your account only; it is not needed in Command Prompt. If your organization manages this policy, ask its administrator instead.
  2. Check Node.js and npm. In the new terminal, run: 
    node --version
npm --version
    Both commands should print a version number.
  3. Install SplatTransform. Run this command on Windows, macOS, or Linux: 
    npm install --global @playcanvas/splat-transform
    Verify that the command is available: 
    splat-transform --version
    If the command is not found, reopen the terminal and check that npm's global executable directory is on PATH. On macOS or Linux, avoid fixing permissions by running npm with sudo; use a Node.js version manager or the npm documentation's global-install guidance instead.

Other PlayCanvas tools

  • SuperSplat Editor runs in a browser; use it to inspect, clean, and edit splat scenes. No local installation is required.
  • SuperSplat Convert runs SplatTransform conversions in the browser, so it is useful for one-off conversions without installing the CLI.
  • The PlayCanvas platform provides browser-based tools for building interactive 3D applications. It is optional and is not required to generate a SplatIt collision sidecar.

See the official SplatTransform documentation and npm's Node.js installation guide for details and troubleshooting.
